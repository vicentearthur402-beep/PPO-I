# Pitacobet - PPO I

Site simples de palpites do Brasileirão. Mostra os jogos da rodada (via TheSportsDB), permite registrar palpites e salva no LocalStorage. Na aba “Placares registrados”, dá para atualizar e comparar com o resultado real (placar exato vale 3 pontos) e excluir palpites.

## Como rodar
Abra a pasta no VS Code e execute com **Live Server** (recomendado).  
Páginas: `index.html` e `oldScores.html`.
